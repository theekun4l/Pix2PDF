# Pix2PDF 📄

Pix2PDF is a simple web application that converts multiple images into a single PDF.

The project has a mobile-friendly frontend and a FastAPI backend that handles image uploads and PDF generation.

## 🚀 Live Demo

[Pix2PDF](https://pix2pdf-utss.onrender.com)

## ✨ Features

- 📷 Upload multiple images
- 👀 Preview selected images before conversion
- 📄 Convert images into a single PDF
- ⬇️ Download the generated PDF
- ⚡ FastAPI backend
- 🌐 Deployed using Render
- 📱 Responsive UI

## 🛠️ Tech Stack

- HTML

### Backend

- img2pdf
